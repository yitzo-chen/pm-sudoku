# 豬猴數獨

單檔網頁數獨：7 種玩法 × 5 個難度，加上每日一題。小豬與小猴陪你解題。

線上玩：https://yitzo-chen.github.io/pm-sudoku/

## 玩法
標準 9×9、迷你 4×4、迷你 6×6、對角線、不規則、殺手、武士（五個 9×9 重疊）。

## 功能
- 5 個難度；每題保證唯一解
- 筆記模式、復原、重複數字標紅
- 計時，各玩法各難度記錄最佳時間（存在這台裝置的瀏覽器，不會上傳）
- 每日一題：標準 9×9，種子為本機日期
- 進度自動存檔，可繼續上一局
- 音效可靜音；支援手機與鍵盤（數字鍵、方向鍵、N 切換筆記、Ctrl+Z 復原）
